# Reviver Kernel

Custom 4.19 kernel for the **Xiaomi Redmi 9 / lancelot**.

Built with **SukiSU Nova** and **SUSFS** support.

---

## ⚠️ Disclaimer

> This kernel is provided as-is.
> Flashing a custom kernel can cause bootloops, data loss, or other issues.
> **Make sure you have a working recovery and a backup before flashing.**

**Supported device:** Xiaomi Redmi 9 / lancelot

**Android:** Only tested on **Android 13**, **Android 16** and **Android 17** S vendor. Other Android versions may not work correctly.

---

## ✨ Features

* SukiSU Nova support
* SUSFS v2.4.0 support
* SELinux Enforcing
* Linux 4.19.325
* NoMount
* WireGuard
* SukiSU Nova extension features
* AVC log spoofing
* More later...

## 🔧 Installation

1. Download the latest kernel ZIP from Releases.
2. Boot into a custom recovery such as OrangeFox.
3. Flash the ZIP.
4. Boot into system.
